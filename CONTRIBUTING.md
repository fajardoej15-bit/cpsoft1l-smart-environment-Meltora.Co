#Contribution Guidelines
##Branch Naming Convention

    Features: feature/<CLICKUP-key>-<short-description>
    Bugfixes: bugfix/<CLICKUP-key>-<short-description>


##Commit Message Format

    <CLICKUP-key> <imperative description> (e.g., SEM-8 Fix application startup error)


##Pull Request Process

    Create feature/bugfix branch from develop.
    Ensure all code tests pass.
    Open PR targeting develop and assign a peer reviewer.
